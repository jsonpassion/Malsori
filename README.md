# Malsori — site

The public site for the Malsori iOS app: `docs/` is served by GitHub Pages at
https://jsonpassion.github.io/Malsori/ (landing page, privacy policy, terms of service).

- Edit the policies in `privacy.md` / `terms.md`, then run `python3 tools/build_pages.py`.
- `docs/hangul.js` is the pronunciation engine the landing page demo runs; it mirrors the app's.

Contact: see the site's Contact link.
